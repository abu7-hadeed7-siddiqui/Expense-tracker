Architectural Highlights for Viva

  • SQLite Concurrency Notice: SQLite uses file-level locking. For safe persistence without data corruption, a single replica (Deployment replica: 1) is paired with a PersistentVolumeClaim.
  • Gunicorn WSGI Server: Production-ready WSGI server hosting Flask inside the lightweight Docker container (`python:3.11-slim`).
  • Probes Configured: Kubernetes HTTP Liveness and Readiness probes target `/health` to automate container self-healing.
  • Cost Safety: Single t2.micro / t3.micro EC2 deployment avoiding EKS, NAT Gateways, or paid load balancers.
